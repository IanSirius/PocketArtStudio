# Pocket Art Studio · 随身输入艺术

把每天遇到的一束光、一句话、一段声音先收进 Obsidian。等你想把其中一段交给创作者，再整理出自己愿意分享的文字。

适用于 Obsidian 桌面版 1.5.0 及以上。插件支持离线记录和整理片段。

## 安装

1. 从 GitHub 仓库的 **Releases** 页面找到 `0.1.0`。下载 `main.js`、`manifest.json` 和 `styles.css`，也可以解压同一版本提供的安装 ZIP。
2. 在你的 Obsidian 仓库里打开 `.obsidian/plugins/`，新建 `pocket-art-studio` 文件夹，将上述三个文件直接放进去。如果你自定义过 Obsidian 配置文件夹，请在自己的配置目录下找 `plugins/`。
3. 回到 Obsidian，在 **设置 → 第三方插件** 中开启第三方插件，然后启用 **Pocket Art Studio**。如果列表里没有出现，重启 Obsidian 后再查看。

安装完成后，默认目录大致如下。

```text
你的仓库/
└── .obsidian/
    └── plugins/
        └── pocket-art-studio/
            ├── main.js
            ├── manifest.json
            └── styles.css
```

## 记下你的第一个片段

1. 打开 Obsidian 命令面板，搜索 **记录生活片段**。你可以沿着一个提问写下几句话，也可以加入照片或音频。
2. 保存后会生成一篇 Markdown 笔记。默认保存到 `随身输入艺术/片段`，可以在插件设置中改用其他文件夹。
3. 运行 **打开片段册**，搜索或筛选已有片段，点开一篇继续编辑。
4. 打开一篇片段笔记，运行 **整理供分享的文字**。核对并编辑要分享的文字，再手动复制。若已在插件设置中填入 Pocket Art Studio 网站地址，可以打开网站，把文字粘贴到想参与的征集里。图片和音频可按征集页面的步骤另行选择。

## 你的素材存在哪里

片段以普通 Markdown 保存，附件保存在你的 Obsidian 仓库中。你可以用平常的方式编辑、备份或同步它们。卸载插件后，仍可直接打开这些文件。

你可以复制整理用的提示词，到自己选择的 AI 工具中使用；粘贴哪些内容由你决定。通过网站投稿时，请在网站上再次核对内容和素材授权。

## 反馈与许可

欢迎在 GitHub Issues 提交建议或报告问题。报告问题时可以附上 Obsidian 版本、操作系统和复现步骤，并使用虚构片段代替自己的私人笔记。
